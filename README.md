<h1 align="center">Welcome to Password Generator 🔐</h1>

> A secure, customizable password generator built with React, TypeScript, and Tailwind CSS

## Features

- [x] Generate strong, secure passwords
- [x] Customize password length (8-32 characters)
- [x] Select character types (uppercase, lowercase, numbers, symbols)
- [x] Password strength indicator
- [x] Copy to clipboard functionality
- [x] Password settings saved in local storage
- [x] Multiple language support (English, Italian, German)

## Demo

You can try the password generator at [https://password-generator.filippofinke.ch](https://password-generator.filippofinke.ch)

## Installation

```sh
npm install
```

## Development

```sh
npm run dev
```

## Build

```sh
npm run build
```
